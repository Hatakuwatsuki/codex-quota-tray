GPT 额度显示器 1.9.17.0

新装
从 GitHub Release 下载 CodexQuotaTray-1.9.17.0.exe 并运行。
三种提示音内嵌于 EXE。以前放在程序旁的同名 WAV 仍可作为自定义音效。
需要查询额度时，在设置里选择 Codex 查询程序并绑定账号。

升级
旧程序还在运行时，把下载的 EXE 放进旧程序所在文件夹，保留下载时的文件名，然后双击新版。
新版会识别同一文件夹里正在运行的旧版，关闭它、替换原 EXE 并重启。
支持退出请求的旧版会正常退出，更早的托盘版可能需要结束进程。
更新会在同目录保留旧 EXE 的备份。原文件名、快捷方式、设置和账号绑定可继续使用。
旧程序已退出时，可将下载的 EXE 改成旧文件名后覆盖。
如果更早的版本尚未建立本工具的账号绑定，请在账号页手动绑定。

使用
右键托盘图标可刷新、打开设置或退出。设置支持中、英、日文。
无绑定时不会查询额度。首次自动找不到 Codex 后，请手动选择程序。
5 小时和 7 天额度分别显示，提醒可按账号设定。
程序设置保存在 EXE 同目录。账号授权由 Codex 和 Windows 凭据库管理。

非官方工具，与 OpenAI 无隶属关系。MIT 许可。
