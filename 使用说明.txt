额度显示器（Codex 额度托盘小工具）
=====================================

【怎么用】
双击「额度显示器.exe」，右下角通知区域会出现一个圆环图标。
第一次运行会自动在桌面建一个快捷方式，桌面图标会跟着额度一起变。

  上段（小）= 5 小时额度
  下段（大）= 7 天额度
  彩色 = 还剩多少，灰色 = 已经用掉多少
  玉石绿 = 已用≤25%，暖琥珀黄 = 中间额度，柔珊瑚红 = 剩余≤25%

鼠标悬停可看「剩余百分之多少 + 多久后恢复」。
右键图标：刷新 / 额度详情 / 额度提醒 / 开启开机自启动 / 创建桌面快捷方式 / 退出。

【前提条件】
电脑上要装好并登录过 Codex 桌面版。
本程序不碰你的账号，只是读本机 Codex 已登录的状态，问一句"我还剩多少额度"。

如果用的是 API Key 登录（不是 ChatGPT 账号登录），可能读不到额度数据，
这是 Codex 接口本身的限制，不是程序坏了。

【第一次运行可能会被拦】
这是自己编译的小工具，没有买数字签名证书，所以 Windows 可能提示
「Windows 已保护你的电脑」或杀毒软件报未知程序。
→ 点「更多信息」→「仍要运行」即可。

【数据存在哪】
就在「额度显示器.exe」同一个文件夹里（日志、缓存、图标）。
想换位置，把整个文件夹搬走就行，别单独挪 exe。

【不想要桌面图标跟着变】
在这个文件夹里新建一个空文件，名字叫：
    disable-desktop-icon.txt
重启程序即可。删掉这个文件就恢复。

【怎么退出】
右键托盘图标 → 退出。不装服务。默认不自启；想开机自动启动，点右键菜单里的「开启开机自启动」即可（再点一次就是关闭）。

【更新】
先退出程序，用新版 exe 覆盖这个文件。

【图标外观更新：可见性增强与柔和三级配色】
保留原版上下细弧、上小下大、圆头与中心菱形。
小尺寸适当加粗，提亮轨道与中心菱形，增强托盘和桌面可辨认度。
已用≤25%为玉石绿；25%至75%之间为暖琥珀黄；剩余≤25%为柔珊瑚红。
托盘、桌面动态图标和 exe 图标使用同一绘制。

【托盘专用微增强】
仅托盘圆环再加厚约15%，中心略放大；桌面图标样式保持不变。

【v1.1 新增】
- 详情页和右键菜单都会跟随 Windows 的深色 / 浅色主题自动切换。
- 详情页改成系统标准控件（进度条、按钮都是 Windows 原生样式）。

> 原来这一版还有「切换模式」（在 Codex 原生模式和网关模式之间切），

【版本】
当前版本：1.6.0.0。右键 exe → 属性 → 详细信息，可以看到文件版本。

【v1.2.1 新增】
- 右键菜单里的那一项会随状态变名字：没开时显示「开启开机自启动」，开了以后显示「关闭开机自启动」，点一下就能切换。
  状态直接写进当前用户的启动项（HKCU\...\Run），不需要管理员权限。

【v1.3 新增：额度提醒】
- 右键菜单多一项「额度提醒」，里面四档：关闭提醒 / 低档 / 中档 / 高档。默认低档。
- 提醒按「已经用掉多少」触发，弹窗里写的是「还剩多少」。
    低档：只剩 25%、只剩 10%
    中档：只剩 75%、只剩 25%、只剩 10%
    高档：只剩 75%、只剩 50%、只剩 25%、只剩 10%
  「只剩 10%」三档都有，这一次是最要紧的——它是唯一能在额度见底前喊住你的那次。
- 「5 小时额度」按上面档位提醒；「7 天额度」不看档位，固定只在剩 25% 和剩 10% 时各提醒一次。
- 弹窗是自己画的卡片（后来改成不走系统通知），不抢焦点，不会打断你正在打的字。
- 额度归零重置后会自动重新生效，数值来回抖动不会重复弹。
- 刚启动程序时不会立刻弹，先默默记下当前用量。
- 注意：自绘弹窗不看系统勿扰设置，照样会出现。
  想彻底不弹，选「关闭提醒」。档位记在程序同目录的 settings.txt 里。

【v1.3 新增：Pro 套餐】
- Plus 有 5 小时和 7 天两个额度，图标是上下两段弧。
- Pro 只有 7 天额度，图标自动变成一个完整的圆环，消耗从 12 点顺时针走一圈，
  悬停提示也只显示一行，详情窗只有一块。
- 套餐是按额度窗口的实际长度自动判断的，不用手动设置。
- 版本号 1.3.0.0。

【v1.3.1 修正】

  当前档位还会加粗，一眼能认出来。
- 菜单里「查看详情」改名为「额度详情」，不再让人猜要查看什么。
- 移除了「切换模式」（Codex 原生模式 / 网关模式）。网关模式不随正式版发布，属 2.0 的内容。
  需要切回原生模式时，用桌面上的「切换到 Codex 原生模式」。

【v1.3.2 新增：自绘提醒弹窗 + 自定义提示音】
- 额度提醒不再用系统通知，改成自己画的卡片：右下角弹出，圆角、深色/浅色跟随系统。
- 弹窗不抢焦点，不会打断你正在打的字；7 秒后自动消失，点一下或点右上角 × 也能提前关。
- 弹出时播放提示音，音频文件是程序同目录的 notify.wav。
- 想换铃声：准备一个 WAV（16 位 PCM，建议 44100Hz、时长 1~2 秒），
  命名成 notify.wav 覆盖程序目录里那个，重启程序即可。
  MP3 不行——.NET 自带的播放器只认 WAV。
- 把 notify.wav 删掉，就只弹窗不响。
- 版本号 1.3.4.0。

  以后自己删掉了不会再自动重建，需要时用右键菜单「创建桌面快捷方式」。

【v1.4 新增：额度耗尽提醒】
- 额度真的用光时会各弹一次：
    5 小时额度用完 → 「5 小时额度已耗尽」
    7 天额度用完 → 「7 天额度已耗尽」
  这两条有自己的提示音：notify-5h-empty.wav / notify-7d-empty.wav。
- 每轮额度只会响一次，额度重置后重新生效，不会反复骚扰。
- 刷新频率改了：5 小时额度每 5 秒查一次，7 天额度每 1 分钟查一次。

【桌面测试工具：测试弹窗】
- 桌面上有个「测试弹窗」快捷方式，双击后会列出四个选项（选择框里选中一行，点「确定」）：
    1. 5 小时额度弹窗（已耗尽）
    2. 7 天额度弹窗（已耗尽）
    3. 25% 额度弹窗
    4. 10% 额度弹窗
  选中点「确定」就会真的弹一次，声音、动画、文案都是正式的。
- 想换铃声就替换程序目录里对应的 wav：
    notify.wav              普通额度提醒
    notify-5h-empty.wav     5 小时额度耗尽
    notify-7d-empty.wav     7 天额度耗尽
- 版本号 1.4.0.0。

[English]
- The right-click menu now has a Language submenu: Auto / 中文 / English. Default is Auto,
  which follows the Windows display language.
- Switching takes effect immediately, no restart needed.
- The tooltip, details window, alert popup, balloons and error messages all follow the setting.

【v1.5.1 修正】

- 版本号 1.5.1.0。
