# CodexQuotaTray · GPT 额度显示器

Windows 托盘工具，可查看已绑定 Codex 账号的 5 小时和 7 天额度，支持多账号、分档提醒与中英日界面。

## 下载与升级

从 [Releases](https://github.com/Hatakuwatsuki/codex-quota-tray/releases) 下载版本号对应的 EXE。
**四种提示音已内嵌**：普通提醒、5 小时额度耗尽、7 天额度耗尽、额度恢复。

旧版运行时，将新版放到旧程序所在文件夹，保留下载文件名并双击。程序会退出旧版、替换原 EXE 并以原文件名重启；旧版已退出时，可以改名直接覆盖。更新会在同目录保留旧 EXE 的备份。

## 功能

- 最多同时绑定 5 个 Codex / ChatGPT 账号，托盘、桌面图标和悬浮窗分别显示每个账号的额度
- 5 小时与 7 天额度分开显示，悬停可看剩余百分比和恢复时间
- 提醒分四档（关闭 / 低 / 中 / 高），可按账号单独设定；额度恢复时另有单独提示
- 额度用尽时提示一次，提示音与通知滑入同步
- 设置页分账号、显示、额度提醒、通用四页，界面支持中文 / English / 日本語

## 编译

在仓库根目录运行 `powershell -File src/rebuild.ps1`，生成 `build/CodexQuotaTray.exe`。仓库里的 WAV 用作编译资源。

更多说明见 [使用说明](使用说明.txt)。

## 隐私

程序只读取本机 Codex 已登录的账号状态，并向 OpenAI 查询额度，不发送模型对话。账号授权保存在本机 Windows 凭据库，不随 exe 复制到其他电脑。

非官方工具，与 OpenAI 无隶属关系。MIT 许可。
