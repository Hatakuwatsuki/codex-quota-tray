# CodexQuotaTray · GPT 额度显示器

Windows 托盘工具，可查看已绑定 Codex 账号的 5 小时和 7 天额度，支持多账号、分档提醒与中英日界面。

当前版本 1.9.65.0。设置「通用」可开启「有更新时自动更新」：检测到新版后在空闲时静默下载并自动替换。

## 下载与升级

从 [Releases](https://github.com/Hatakuwatsuki/codex-quota-tray/releases) 下载版本号对应的 EXE。
**六种提示音已内嵌**：普通提醒、5 小时额度耗尽、7 天额度耗尽、额度恢复、推荐用量提醒、重置券提醒。

程序启动后会自动检查 GitHub 上的正式版本，持续运行时每小时检查一次，也可以在设置「通用」页手动检查。发现新版本时，点左下角的「更新」查看进度，更新完成后程序会自行启动。

下载新版后保留带版本号的文件名直接双击也可以，程序会找到旧版所在的位置并原地替换；旧版已退出时，也可以把新版改名后覆盖旧文件。更新会在同目录保留旧 EXE 的备份。

## 功能

- 最多同时绑定 5 个 Codex / ChatGPT 账号，托盘、桌面图标和悬浮窗分别显示每个账号的额度
- 5 小时与 7 天额度分开显示，悬停可看剩余百分比和恢复时间；悬停浮窗不会闪出多余的方块
- 提醒分四档（关闭 / 低 / 中 / 高），可按账号单独设定；额度恢复时另有单独提示。开启声音时可调节五档音量并试听，关闭后仍显示弹窗
- 额度用尽时提示一次，提示音与通知滑入同步
- 自动检查更新，可开启有更新时自动更新，也可在程序内一键下载并安装新版本
- 重置券提醒：只读查询 Codex 的重置券张数与最近过期时间，拿到新券时告知，距过期不足 24 小时再提醒一次，全程不调用任何核销接口
- 推荐用量提醒：按 7 天周期的剩余额度与天数动态算出今日建议上限，Plus 与 Pro 都适用
- 设置页分账号、显示、额度提醒、通用四页，界面支持中文 / English / 日本語

## 编译

在仓库根目录运行 `powershell -File src/rebuild.ps1`，生成 `build/CodexQuotaTray.exe`。仓库里的 WAV 用作编译资源。

更多说明见 [使用说明](使用说明.txt)。

## 隐私

所有的数据都只在本地运行：设置、日志和账号状态在 exe 同目录，账号资料在 `%LOCALAPPDATA%\CodexQuotaTray\accounts`。

非官方工具，与 OpenAI 无隶属关系。MIT 许可。
